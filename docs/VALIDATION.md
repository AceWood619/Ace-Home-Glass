# Validation checklist

- [ ] Back up current Ace Home dashboard JSON.
- [ ] Validate entity IDs against live registry.
- [ ] Validate custom cards/resources are installed.
- [ ] Confirm theme is loaded and selected.
- [ ] Ensure camera URLs contain no credentials.
- [ ] Ensure private household data is excluded from public repo.
- [ ] Test light toggles and brightness.
- [ ] Test media play/pause, next/previous, mute, volume.
- [ ] Test D-pad only against the intended device.
- [ ] Test camera stream and microphone separately from talkback.
- [ ] Verify bedroom node availability and firmware versions.
- [ ] Test desktop, iPhone, and Pi HDMI layout.
- [ ] Test HA and kiosk restart persistence.
- [ ] Verify rollback restores the previous dashboard.
